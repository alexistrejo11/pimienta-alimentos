# Producto POS

Este directorio contiene la definición de producto del nuevo Punto de Venta (POS). Es independiente de la implementación: no define tablas, APIs ni tecnologías salvo cuando una restricción operativa lo hace necesario.

## Documentos

- [Contexto y problema](01-contexto-y-problema.md): situación actual, usuarios y restricciones del entorno.
- [Propuesta de MVP](02-propuesta-mvp.md): resultado que se busca entregar y reglas ya acordadas.
- [Decisiones pendientes](03-decisiones-pendientes.md): temas que debemos resolver antes de especificar el sistema en detalle.

## Estado

Los documentos registran decisiones confirmadas en la conversación al 3 de septiembre de 2026. Una decisión pendiente no debe suponerse ni implementarse hasta discutirla.
