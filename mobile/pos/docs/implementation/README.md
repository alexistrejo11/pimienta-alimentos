# Plan técnico de implementación

Esta carpeta convierte la arquitectura y workflows en un plan de trabajo ejecutable. No contiene código ni sustituye las especificaciones funcionales.

## Documentos

- [Blueprint técnico](01-blueprint-tecnico.md): estructura inicial, dependencias y reglas de construcción.
- [Datos reales e integración](02-datos-e-integracion.md): seed de desarrollo, bootstrap y descubrimiento del backend.
- [Fases y estrategia de pruebas](03-fases-y-pruebas.md): cortes verticales, pruebas automatizadas y validación manual.

## Regla de entrega

Cada fase debe terminar con:

1. un flujo demostrable con datos realistas;
2. pruebas automatizadas proporcionales a su riesgo;
3. una lista corta de pruebas manuales en emulador y, cuando aplique, tablet/periférico real;
4. documentación actualizada si una decisión cambia.
